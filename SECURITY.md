# Security Policy

## Supported Versions

Security updates and patches are actively applied to the following versions of LOWKEY:

| Version | Supported          |
| :---    | :---               |
| `main`  | :white_check_mark: |
| `< 1.0` | :x:                |

---

## Reporting a Vulnerability

The LOWKEY engineering team takes the security of our data retrieval engines, vector databases, and dependencies seriously.

If you believe you have discovered a vulnerability, security flaw, or sensitive data exposure:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report via email to **`ritigyam2@gmail.com`** with the subject line `[SECURITY] LOWKEY Vulnerability Report`.
3. Include the following details in your report:
   - Detailed description of the vulnerability.
   - Exact steps or code snippet required to reproduce the behavior.
   - Potential impact of the issue (e.g. arbitrary code execution, denial of service, memory leak).
   - Any proposed mitigations or remediations.

---

## Response & Disclosure SLA

* **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **48 hours**.
* **Assessment:** The engineering team will triage and assess the report within **5 business days**.
* **Remediation:** If verified, a patch will be prepared, tested, and released as a priority.
* **Coordinated Disclosure:** We kindly ask that you keep information about the issue confidential until a fix has been deployed and publicly announced.
